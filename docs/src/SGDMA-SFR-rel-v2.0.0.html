1 기준 구성

같은 axi_dmac 계열 RTL이라도 파라미터가 다르면 레지스터의 필드 폭, 리셋값, 쓰기 가능 여부가 달라집니다. 이 장에서 이 문서가 전제로 하는 구성을 고정합니다.

1.1 Top 파라미터

sg_dma_top(sg_dma_top.v 43~53행)의 파라미터는 9개입니다. TB는 ADDR_WIDTH, DATA_WIDTH, AXI_ID_WIDTH를 기본값과 같은 값으로 넘깁니다.
